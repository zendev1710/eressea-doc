# `ORIGIN`

**`ORIGIN`**` `*`x y`*  

Cet ordre permet à une unité de modifier le système de coordonnées de la faction.  
Cette opération place l'origine (0,0) du système de coordonnées de la faction dans la région (x,y).  

!!! note
    L'ordre s'applique au plan dans lequel se trouve la faction (voir aussi [Astral][lastral]).
