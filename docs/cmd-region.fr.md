# REGION

`REGION x,y; <Nom de la région>`  

L'ordre `REGION` n'a aucune fonction pour Eressea.  

Cet ordre est simplement inséré dans les [ordres][ordres] pour permettre à d'autres programmes (par exemple [ECheck][echeck-fr-id]) de reconnaître plus facilement les régions individuelles.
