# `EINHEIT`

**`EINHEIT`**` `*`<einheit-nr>`*  

Mit diesem Befehl beginnt man die Befehlseingabe für eine der eigenen Einheiten.  

```text
EINHEIT 45
    NACH WESTEN
EINHEIT 46
    BETRETE GEBÄUDE 7
```
