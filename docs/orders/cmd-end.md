**`END`**

Dieser Befehl beendet die Eingabe der Befehle für eine temporäre Einheit, die mit [`MAKE TEMP`] erschaffen wurde.

     MAKE TEMP 1
       NAME UNIT "Joggonarag Thorggh"
       RECRUIT 1
       LEARN Magie
     END
