**`END`**

Cette instruction clôt les ordres d'une unité temporaire créée par [[cmd-make|`MAKE TEMP`]].

```text
MAKE TEMP 1
    NAME UNIT "Joggonarag Thorggh"
    RECRUIT 1
    LEARN Magic
END
 ```
