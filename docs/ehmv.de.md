# EHMV

**Eressea Hex Map Viewer**, kurz [EHMV], ist ein Karten- und Reportbetrachter für das eMail-Spiel [Eressea].  

Im Jahr 2000 war das Programm laut einer Umfrage der am meisten genutzte Eressea-Client.  

Die Entwicklung wurde jedoch mittlerweile eingestellt.
