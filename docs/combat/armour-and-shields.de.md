# Rüstungen und Schilde

Auf dieser Seite sind die Eigenschaften einzelner Rüstungen und Schilde aufgeführt.  
Die Berechnungsregeln stehen unter [Krieg][krieg], die aggregierten Werte in der [Übersichtstabelle][rustung].

## Rüstungen

### Kettenhemd

*Eigenschaften eines Kettenhemds im Kampf.*

| Eigenschaft                              |  Wert |
| ---------------------------------------- | ----: |
| Panzerung                                |     3 |
| Änderung der Chance, getroffen zu werden | +15 % |

### Plattenpanzer

*Eigenschaften eines Plattenpanzers im Kampf.*

| Eigenschaft                              |  Wert |
| ---------------------------------------- | ----: |
| Panzerung                                |     5 |
| Änderung der Chance, getroffen zu werden | +30 % |

### Adamantiumrüstung

Rüstung, die aus [Adamantium][adamantium-de-id] gefertigt wird.

Diese Rüstung bietet den **besten** Schutz.

*Eigenschaften einer Adamantiumrüstung im Kampf.*

| Eigenschaft                              |  Wert |
| ---------------------------------------- | ----: |
| Panzerung                                |     7 |
| Änderung der Chance, getroffen zu werden | +10 % |

### Laenkettenhemd

Wie alle **Laenwaffen und -rüstungen** erhöht es die [Magieresistenz][war-table-magieresistenz-id] um **30 %**.

*Eigenschaften eines Laenkettenhemds im Kampf.*

| Eigenschaft                              | Wert |
| ---------------------------------------- | ---: |
| Panzerung                                |    6 |
| Änderung der Chance, getroffen zu werden |  0 % |
