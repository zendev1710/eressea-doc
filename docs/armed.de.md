# Bewaffnet

Eine Einheit gilt als bewaffnet, wenn sie über ein [[liste-der-talente|Kampftalent]] (Hiebwaffen, Stangenwaffen, Bogenschießen, Armbrustschießen, Katapultbedienung) und mindestens eine Waffe des entsprechenden Typs verfügt.

Eine Einheit muss bewaffnet sein, um eine Region [[bef-bewache|bewachen]] zu können.

Auch für das Steuereintreiben muss man bewaffnet sein, wobei auch nur die Personen Steuern eintreiben, die eine Waffe haben.

[[monster|Monster]] und andere Einheiten mit dem Talent 'Waffenloser Kampf' gelten auch dann als bewaffnet, wenn sie keine Waffe tragen.
Sie sind sozusagen mit Zähnen und Klauen (oder Tentakeln, Fangarmen usw.) bewaffnet.
