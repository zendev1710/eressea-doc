# `NUMBER`

**`NUMBER UNIT`**` ``[`*`<nouvel identifiant>`*`]`  
**`NUMBER FACTION`**` ``[`*`<nouvel identifiant>`*`]`  
**`NUMBER SHIP`**` ``[`*`<nouvel identifiant>`*`]`  
**`NUMBER BUILDING`**` ``[`*`<nouvel identifiant>`*`]`  

Cela vous permet d'attribuer un nouvel identifiant à une unité, un bateau, un bâtiment ou même votre propre faction.  

Un identifiant est constitué d'au plus 4 chiffres et/ou lettres en minuscules.  
Les zéros non significatifs ne sont pas autorisés.  

Si l'identifiant spécifié est déjà pris, l'élément renseigné conservera son identifiant courant.  

Si dans l'ordre aucun identifiant n'est précisé, un identifiant aléatoire sera attribué.
