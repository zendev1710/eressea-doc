# `UNIT`

**`UNIT`**` `*`<unit-id>`*  

Avec cet ordre, tu commences à renseigner les ordre pour l'une de tes unités.  

```text
UNIT 45
    MOVE WEST
UNIT 46
    ENTER BUILDING 7
```
