# Andere Gebäude

Gebäude werden mit dem Befehl [MACHE gebäudetyp] gebaut und mit [MACHE gebäudetyp gebäude-nr][MACHE gebäudetyp] wird an einem Gebäude weitergebaut. Beispiele: MACHE [LEUCHTTURM] oder MACHE [HAFEN] xyz. Für diese Gebäude ist ein Mindesttalentwert in Burgenbau erforderlich, der in der Tabelle angegeben ist. Außerdem können einige Gebäude nur bis zu einer bestimmten Größe ausgebaut werden.

Hier zunächst eine zusammenfassende Tabelle, nähere Erklärungen folgen darunter.

Gebäude

  [MACHE gebäudetyp]: ./cmd-make.md "MACHE"
  [LEUCHTTURM]: #leuchtturm
  [HAFEN]: #hafen
