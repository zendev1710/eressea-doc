# Monsters

The faction of monsters is currently the only NPC faction in Eressea. It had the faction ID 0, but since around round 572 it has had the ID (ii). Why actually (ii)? If you convert ii from Base36 to the decimal system, you get 666.

There are many different monster races with different characteristics and abilities. The most common are the various [undead types] as well as [dragons] and their followers. Some monster types are rather rare, if not unique. Others, such as the [braineaters], are (almost) only found in certain areas.

In certain circumstances, players can also own monster units (e.g. skeletons).
