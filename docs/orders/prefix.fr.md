# `PREFIX`

**`PREFIX`**`[`*`préfixe`*`]`  

Avec l'ordre `PREFIX`, vous pouvez préfixer les désignations de peuples des unités de votre faction (ou de vos groupes) dans le rapport.  
Le préfixe n'a aucun autre effet.  

Sans paramètres, l'ordre supprime un préfixe existant.  

Les préfixes actuellement pris en charge sont :

- `dark`, `light`, `shadow`, `gray`, `gloomy`
- `small`, `high`
- `hill`, `mountain`, `forest`, `swamp`
- `snow`, `sun`, `moon`, `fog`, `frost`
- `lake`, `valley`, `cave`
- `blood`, `wild`, `chaos`, `night`

L'ordre peut être utilisé aussi bien pour une faction qu'un groupe.  
Il est donc possible de donner à chaque [groupe][cmd-group-fr-id] d'une faction son propre préfixe.
