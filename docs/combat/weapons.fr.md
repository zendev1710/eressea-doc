# Armes

Cette page répertorie les propriétés des armes individuelles.  
Pour le tableau agrégé, voir [ce tableau][armes-tableau-de-synthese].

## Armes de mêlée

Les armes de mêlée sont les armes utilisables au combat en corps à corps.  

Toute arme de mêlée requiert d'avoir acquis la compétence de [mêlée][skill-melee-fr-id]{title="Melee"} .  

Les armes de mêlée infligent autant de dégâts à pied qu'à cheval.
