# BANNER

**`BANNER "<texte>"`**  

Cet ordre vous permet de définir une description qui apparaîtra dans la liste d'adresses de l'[`OPTION ADDRESS`][cmd-option-fr].  
Il peut contenir le nom du joueur ou une adresse e-mail alternative pour les autres joueurs.  
Il est également noté ici si un [remplacement de vacances][triche] joue.  

**Exemple** :

```text
BANNER "Henning Peters, Bremen. eMail also faroul@gmx.fr"
```
