# UNIT

**`UNIT <unit-id>`**  

Avec cette instruction, vous commencez à renseigner les ordre à donner à l'une de vos unités.  

```text
UNIT unt1
    MOVE WEST
UNIT unt2
    ENTER CASTLE cstl
```
