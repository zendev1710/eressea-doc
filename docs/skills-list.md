# List of skills
<!-- TODO: check translations - seem to be bad sometimes -->

Here is a list of all skills units can learn in Eressea.  

This is just a short overview, all details are given in the respective chapters.

[](){ #skill-alchemy-id }

## Alchemy

Make [potions][alchemy] from [[herbs]]. Learning costs 200 silver per person. There can be no more than three alchemists per faction.

[](){ #skill-armoursmithing-id }

## Armoursmithing

Produce iron, laen, and adamantium plates (see [[items]]).

[](){ #skill-bow-id }

## Bow

With a bow: fight. With the taxation skill: collect taxes (TAX).

[](){ #skill-cartmaking-id }

## Cartmaking

Construction of carts and catapults from wood. A cart can be built with 5 wood. A unit can make 1 cart per person and skill level, a catapult requires level 5 and 10 wood.

[](){ #skill-catapult-id }

## Catapult

With a catapult and ammunition: fight. Can't be used to collect taxes.

[](){ #skill-crossbow-id }

## Crossbow

With a crossbow: fight. With the taxation skill: collect taxes (TAX).

[](){ #skill-endurance-id }

## Endurance

Gives more hit points, making a unit more resistant to damage in combat or due to lack of food (see this [table][table-endurance-id]).

[](){ #skill-entertainment-id }

## Entertainment

Entertain the peasants. If the peasants have enough silver, units can earn 20 silver per person and skill level.

[](){ #skill-espionage-id }

## Espionage

Necessary to use the order [[cmd-spy]] and thus obtain secret information about units of other factions (skills, true belonging to a faction, ...). Learning espionage costs 100 silver per person per week.

[](){ #skill-forestry-id }

## Forestry

Felling trees to make wood or mallorn (see [resources][deep-in-the-forest]).

[](){ #skill-herbalism-id }

## Herbalism

Find [[herbs]] to make [potions][alchemy]. Learning cost is 200 Silver per week. With a high level you can give the orders [`RESEARCH HERBS`][cmd-research], [`MAKE SEEDS`][cmd-make] (see [production][production-id]) and [[cmd-plant]]. Despite high skill level, you may sometimes find few or no herbs.

[](){ #skill-magic-id }

## [[magic]]

This allows you to cast combat spells and other types spells. Learning magic [costs silver][magic] depending on the level.

[](){ #skill-masonry-id }

## Masonry

Build [castles and other buildings][buildings].

[](){ #skill-melee-id }

## Melee

With a "melee" weapon (sword, claymore, axe, laensword): fight. With the taxation skill: collect taxes (TAX).

[](){ #skill-mining-id }

## Mining

Extract iron, laen, or adamantium.  
You can extract **one iron per person and per skill level**.  

Note that deposits are limited by level (see [resources][resources]).
You can only see the amount of iron in the top layer.
For prospecting you can only see layers up to (mining level X 2).
If the layer is deeper, you won't see anything.

!!! note
    [laen][laen-id] mining needs a [mine][mine-id] and a skill level of **7**.  
    [adamantium][adamantium-id] mining needs a [mine][mine-id] and a skill level of **8**.

[](){ #skill-perception-id }

## Perception

The unit is always on the lookout for camouflaged units. For example this allows you to prevent theft (see [perception][skill-perception-id]).

[](){ #skill-polearm-id }

## Polearm

With a polearm (spear, mallorn spear, lance, mallorn lance, halberd): fight. With the taxation skill: collect taxes (TAX).

[](){ #skill-quarrying-id }

## Quarrying

Produce stones and catapult ammunition (with at least level 3). One stone can be made per person and skill level.

Note that deposits are limited by level (see [resources][about-mining]). You can only see the number of stones in the top layer. If there are no stones in the layer (skill level \* 2), you can't see anything.

[](){ #skill-riding-id }

## Riding

With a [horse][horse-and-carriage]: Starting from riding 1 faster movement; starting from riding 2 you may get the cavalry bonus in combat. Walk with (4 x riding level) + 1 horses or ride with (2 x riding level) horses.

[](){ #skill-roadwork-id }

## Roadwork

Building [[roads]] from stones. One stone can be built per person and skill level.

[](){ #skill-sailing-id }

## Sailing

With a ship: allows you to sail. All units on the ship with sailing skill count as crew.

[](){ #skill-shipcraft-id }

## Shipcraft

Construct and repair ships with wood (see [ships][ships-id]).

[](){ #skill-stealth-id }

## [[stealth]]

The unit is always cloaked and only visible to units with the same or greater perception skill. Successfully camouflaged units can [steal][cmd-steal] or thwart [guarding][cmd-guard] units.

[](){ #skill-tactics-id }

## [[tactics]]

In combat, the side with the best tactician has extra attacks (see [mustering][to-arms]). Learning costs 200 silver per person.

[](){ #skill-taming-id }

## Taming

This skill is required to get [horses][horse-and-carriage]. It can be used in two ways:

- With [`MAKE SEEDS`][cmd-make]`[`*`amount`*`] horse` a unit captures horses present in the region, at a rate of one horse per person and per level of taming skill.
- With [`GROW HORSES`][cmd-grow] you can reproduce horses from existing horses, but you must be in a [stable][stable].

[](){ #skill-taxation-id }

## Taxation

Collect taxes from peasants. Per skill level and per person armed and trained with a weapon, units can collect 20 silver from peasants.

This skill does not increase when used, nor does the corresponding weapon skill.

[](){ #skill-trade-id }

## Trade

In regions with a castle: buy and sell luxury goods. Per person and skill you can trade 10 goods (see [trade][silver-trade-id] and [[cmd-buy]]).

[](){ #skill-unarmed-combat-id }

## Unarmed combat

Player races cannot learn this skill.  

It is only available for monsters and other special races where it works like a close combat skill without a weapon.

[](){ #skill-weaponsmithing-id }

## Weaponsmithing

Produce weapons from wood and metals (see [[items]]).

Continue reading: [stealth][stealth-id].
