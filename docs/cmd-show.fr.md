# SHOW

**`SHOW "<sort>"`**  
**`SHOW "<item>"`**  
**`SHOW "<potion>"`**  
**`SHOW ALL SPELL`**  
**`SHOW ALL POTION`**  
**`SHOW "<peuple>"`**  

Affiche la description d'un sort, la recette d'une potion ou la description d'un objet.  

L'unité qui donne l'ordre doit posséder l'objet ou avoir connaissance du sort ou de la potion.  
Si un objet se trouve dans la [réserve de faction][reserve-de-faction], n'importe quelle unité de la faction peut donner l'ordre `SHOW`.

Certaines caractéristiques relatives aux peuples peuvent également être affichées, par exemple pour les [familiers][familiers-id].  
Pour cela, le peuple de l'unité doit correspondre au paramètre spécifié.
