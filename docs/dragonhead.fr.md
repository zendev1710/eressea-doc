# Tête de Dragon

Une tête de dragon peut être obtenue lorsqu'un [dragon] est tué.

Les sorts de magie suivants en ont besoin pour être lancés :

- [Invocation du Dragon] (École de Magie Draig)
- [Créer un [DreamEye]] (École de Magie Illaun)
