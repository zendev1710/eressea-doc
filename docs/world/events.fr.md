## Migration paysanne

<!-- From [https://wiki.eressea.de/index.php?title=Bauernwanderung&oldid=2447] -->

Les paysans peuvent se déplacer d'une région à l'autre.  
Les paysans migrants ne travaillent pas pendant la semaine de migration, mais consomment quand même de l'argent, dans la région cible.  

Les paysans migrent pour différentes raisons.

### Fuite devant les monstres

Les paysans fuient les [monstres][monstres].  

Si des monstres [apparaissent][apparition-de-monstres] dans une région, ils chassent chaque semaine certains paysans.  
Le nombre de paysans déplacés dépend du type et du nombre de monstres.  

Les monstres invoqués par un mage peuvent également chasser les paysans.  

### Surpopulation

Les paysans émigrent à cause de la surpopulation.  
S'il y a plus de paysans que [d'emplois][cmd-work-fr] dans une région, une partie des paysans sans emploi émigre vers les régions voisines.

## Pauvreté

Les paysans émigrent également à cause de la pauvreté.
