**`END`**

This orders stops entering orders for a temporary unit that starts with [[cmd-make|`MAKE TEMP`]] was created.

```text
MAKE TEMP 1
    NAME UNIT "Joggonarag Thorggh"
    RECRUIT 1
    LEARN Magie
END
 ```
