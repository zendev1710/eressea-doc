# EHMV

**Eressea Hex Map Viewer**, [EHMV] en abrégé, est un visualiseur de cartes et de rapports pour le jeu par courrier électronique [Eressea].  

En 2000, selon une enquête, le programme était le client d'Eressea le plus utilisé.  

Cependant, le développement a maintenant été interrompu.
