# ZERSTÖRE

*[Langer Befehl][kurze-und-lange-befehle].*  

**`ZERSTÖRE`**`[`*`stufen`*`]`  
**`ZERSTÖRE`**`[`*`stufen`*`] STRASSE`*`richtung`*  

Eine Einheit, die das Kommando über ein [Schiff][schiff] oder ein [Gebäude] hat, kann dieses jederzeit mit diesem Befehl verkleinern oder ganz zerstören. Dazu braucht sie kein Talent. Der Parameter *stufen* bezeichnet dabei bei Gebäuden die Größenpunkte, um die das Gebäude verkleinert werden soll, bei Schiffen die Prozentpunkte. Wird kein Parameter angegeben, so wird die Struktur komplett zerstört. Schiffe können allerdings nur in Küstengebieten verkleinert oder versenkt werden, die Besatzung weigert sich, das Schiff auf hoher See zu beschädigen!

Mit `ZERSTÖRE [`*`stufen`*`] STRASSE`*`richtung`* kann man eine [Straße][strassen-id] abreißen oder beschädigen. Dabei darf keine Partei die Region bewachen, die nicht HELFE BEWACHE zur eigenen Partei gesetzt hat. Um eine Straße zu beschädigen oder zu zerstören, benötigt eine Einheit das Talent Straßenbau. Man kann einen Größenpunkt pro Talentpunkt zerstören.

Eine Einheit kann jeweils nur eine Struktur (Gebäude, Straße, Schiff) pro Woche zerstören.
