# ORIGIN

**`ORIGIN`**` `*`x y`*  

A unit can offset the faction's coordinate system.  
This will place the (0,0) origin of the faction's coordinate system into the region (x,y).  

!!! note
    The order applies to the plane in which the faction is located (see also [Astral Space][the-astral-space]).
