    Discussion: Short description¶

    Under "S/L" it is noted whether the [Order] is a short or long order, i.e. whether it is executed immediately (and further orders are possible afterwards) or takes a whole round to execute. S is a short order, L is a long order.

    \(L\) denotes a pseudo-long [Order] that can be given to a unit multiple times. However, no other long order can be executed.

    Brief description of orders.

    Order Description S/L
    ATTACK unit-id attacks the unit (L)*
    BANNER "text" Sets text for the address list S
    BUY number luxury-item buy luxury number L***
    CARRY unit-id transport another unit S
    CAST [REGION x y] [LEVEL n] "spell" ... Cast spells (L)
    CLAIM number item Fetches items from faction pool S
    COMBAT set the combat behavior S
    COMBATSPELL [LEVEL n] "spell" [NOT] set spell for combat S
    COMBAT AGGRESSIVE S
    COMBAT DEFENSIVE S
    COMBAT FLIEHE S
    COMBAT HELP [NOT] the unit is [NOT] helped in the fight S
    COMBAT NOT S
    COMBAT REAR S
    CONTACT unit-id contact foreign unit S
    DEFAULT order sets the default order for the next turn S
    DESCRIBE BUILDING "text" S
    DESCRIBE PRIVATE "text" unit description for the owner S
    DESCRIBE REGION "text" S
    DESCRIBE SHIP "text" S
    DESCRIBE UNIT "text" describes object S
    DESTROY building, ship, or road L
    EMAIL email@adresse sets the e−mail the report is sent to S
    END ends a MAKE TEMP block S
    ENTERTAIN [amount] earn 20 or more silver (max. 20 silver/skill lvl) L
    ENTER BUILDING building-id Enter a building S
    ENTER SHIP ship-id Enter a ship S
    ERESSEA faction-id "password" beginning of faction's orders S
    FOLLOW SHIP ship-id follows a ship (L)**
    FOLLOW UNIT unit-id follows a unit (L)**
    FORGET skill forget a skill S
    GIVE 0 number MEN S
    GIVE 0 number SILVER throwing away objects S
    GIVE 0 number item S
    GIVE unit-id COMMAND give a unit ship/ building control S
    GIVE unit-id HERB give a unit all herbs S
    GIVE unit-id UNIT give unit to a foreign faction S
    GIVE unit-id [EACH] number MEN give a unit men S
    GIVE unit-id [EACH] number SHIP give SHIP to form convoys S
    GIVE unit-id [EACH] number SILVER give silver S
    GIVE unit-id [EACH] number item give number S
    GROUP ["name"] forms groups of units S
    GROW HERB L
    GROW HORSES breed horses, needs a stable L
    GROW TREES L
    GUARD [NOT] guard the region S
    HELP faction-id ALL [NOT] set up/revoke an unilateral alliance S
    HELP faction-id COMBAT [NOT] S
    HELP faction-id FACTIONSTEAL [NOT] S
    HELP faction-id GIVE [NOT] S
    HELP faction-id GUARD [NOT] S
    HELP faction-id SILVER [NOT] S
    HIDE FACTION NUMBER nummer disguised as another faction S
    HIDE FACTION [NOT] S
    HIDE race Demon: disguise as another race S
    HIDE [level] set hide level S
    LANGUAGE en/de Change Language for orders S
    LEARN AUTO skill learn or teach a skill L
    LEARN skill learn a skill L
    LEAVE leave ship or building S
    LOCALE en/de no function (only for tools) S
    MAKE baue weiter an Gebäude/Schiff ?? L
    MAKE TEMP unit-alias-nr ["name"] creates a new unit S
    MAKE [number] HERB pick herbs in a region L
    MAKE [number] item make an number L
    MAKE [number] trank make a potion L
    MAKE [stufe] BOAT build a boat L
    MAKE [stufe] CARAVEL L
    MAKE [stufe] DRAGONSHIP build a dragonship L
    MAKE [stufe] GALLEON L
    MAKE [stufe] LONGBOAT build a longboat L
    MAKE [stufe] ROAD direction build road L
    MAKE [stufe] SHIP [ship-id] extend a ship L
    MAKE [stufe] TRIREME L
    MAKE [stufe] building-type [building-id] erect or extend a building L
    MESSAGE BUILDING building-id "text" Send a message S
    MESSAGE FACTION faction-id "text" Send a message S
    MESSAGE REGION "text" Send a message S
    MESSAGE SHIP ship-id "text" Send a message S
    MESSAGE UNIT unit id "text" Send a message S
    MOVE direction [direction]... move unit L
    NAME BUILDING "name" S
    NAME FACTION "name" S
    NAME FOREIGN BUILDING building-id "name" S
    NAME FOREIGN FACTION faction-id "name" S
    NAME FOREIGN SHIP ship-id "name" S
    NAME FOREIGN UNIT unit-id "name" names the specified foreign object S
    NAME REGION "name" S
    NAME SHIP "name" S
    NAME UNIT "name" names the specified object S
    NEXT ends the orders of a faction S
    NUMBER BUILDING [new-id] S
    NUMBER FACTION [new-id] S
    NUMBER SHIP [new-id] S
    NUMBER UNIT [new-id] gives a new id S
    OPTION ADRESSES [NOT] S
    OPTION AUSWERTUNG [NOT] Set / Revoke Options S
    OPTION BZIP2 [NOT] S
    OPTION COMPUTER [NOT] S
    OPTION MATERIALPOOL [NOT] S
    OPTION PUNKTE [NOT] S
    OPTION SILBERPOOL [NOT] S
    OPTION STATISTICS [NOT] S
    OPTION TALENTVERSCHIEBUNG [NOT] S
    OPTION ZIPPED [NOT] S
    OPTION ZUGVORLAGE [NOT] S
    ORIGIN [x y] Sets the origin to x,y S
    PASSWORD "new-password" set new password S
    PAY NOT [building-id] do not pay a maintenance S
    PIRACY [faction_1][faction_2]... Set Piracy L
    PLANT [number] HERB Plant herbs L
    PLANT [number] MALLORNSEEDS Plant mallorn seeds L
    PLANT [number] SEEDS Plant seeds L
    PLANT [number] TREES Plant seeds L
    PREFIX [präfix] prepend the race name with a prefix S
    PROMOTE Promote a unit to hero S
    QUIT "password" [FACTION faction-id] quit the game [merge with another faction] S
    RECRUIT number recruit men (persons of your race) S
    REGION x,y no function (only for tools) S
    RESEARCH HERB search for herbs L
    RESERVE number "item" reserve number S
    RESERVE number SILVER reserve silver S
    RIDE unit-id be transported by unit−id L
    ROUTE direction [direction]... Travel L
    SELL number luxury-item sell luxury goods (L)****
    SHOW "spell" retrieve spell description S
    SORT AFTER unit-id S
    SORT BEFORE unit-id sort unit in report S
    SPY unit-id spy a unit L
    STEAL unit-id steal 50 Silver or more L
    TAX [amount] tax peasants (max. 20 silver/skill lvl) L
    TEACH unit-id [unit-id]... teach units L
    UNIT unit-id beginning of a unit's orders S
    USE [number] trank uses alchemical potion S
    WORK earns 10 silver or more L
    // permanent comment S

    * voir The aftermath of battle
    **If the tracked unit does not move, another long order can be executed instead
    ***can be combined with SELL
    ****can be combined with BUY
