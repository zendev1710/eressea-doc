# Bauernvermehrung

Bauern vermehren sich mit einer Rate von 1 Promille pro Woche. Es wird aufgerundet, d.h. in einer Woche kommen pro angefangene 1000 Bauern einer dazu.

Mittels [Bauernlieb][alchemie-id] kann die Vermehrungsrate deutlich angehoben werden. Bis zu 1000 Bauern erhalten dadurch für eine Woche im Mittel die zehnfache Chance, sich zu vermehren. Dieser Effekt unterliegt jedoch deutlichen Schwankungen.
