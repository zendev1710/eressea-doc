# Fonts

Quelle police de caractères (google font) pour une documentation fournie d'un jeu de stratégie dans un monde du style des mondes de Tolkien ?

Pour une documentation de jeu de stratégie style Tolkien, optez pour des polices **Serif** (avec empattements) comme :

- Merriweather,
- Lora, ou
- Playfair Display

pour un aspect classique, médiéval, et lisible, combinées à des polices Sans-serif comme :

- Noto Sans,
- Roboto (ou Roboto Slab pour un côté plus robuste),
- Lato, ou Open Sans pour les titres, légendes, ou interlignes

afin d'assurer une lisibilité et une cohérence avec le thème fantasy.

- Polices Serif (Corps de texte)
- Merriweather: Très lisible, chaleureuse, idéale pour de longs textes imprimés ou web, évoquant un style livre ancien
- Lora: Moderne avec des racines calligraphiques, fonctionne bien pour l'impression et le web, très polyvalente
- Playfair Display: Épique et élégante, parfaite pour les titres et sous-titres, donne une touche sophistiquée
- Polices Sans-Serif (Titres/Compléments)
- Roboto / Roboto Slab: Roboto est moderne et nette. Roboto Slab (avec empattements courts) peut donner un aspect plus technique ou ancien, idéal pour une interface de jeu
- Noto Sans: Une police très complète (plus de 100 langues), lisible, qui assure une bonne cohérence
- Lato / Open Sans: Populaire, lisible, polyvalente, et amicale pour les interfaces ou les interlignes

## Combinaisons Suggérées

- Classique/Médiéval : Merriweather (corps) + Playfair Display (titres) ou Noto Sans (pour les sections techniques)
- Aventureux/Moderne : Lora (corps) + Roboto (titres) ou Montserrat (titres) pour un contraste élégant
- Épique/Solide : Merriweather/Lora (corps) + Roboto Slab (titres/encadrés) pour un look robuste

Conseil : Testez toujours la lisibilité sur une page complète et l'harmonie entre les polices choisies pour vérifier si elles correspondent à l'ambiance "Tolkien" que vous recherchez (fantaisie, histoire, mythologie).
